# Reasoning Script

This project contains a simple Python script `Reasoning.py` that demonstrates basic arithmetic operations and printing.

## Description

The `Reasoning.py` script performs the following actions:
- Prints "Hello World"
- Defines variables `a` and `b`
- Calculates the sum `c = a + b`
- Prints the values of `a`, `b`, and `c`

It appears to be a source file from a Databricks notebook.

## Usage

To run the script, execute the following command in your terminal:

```bash
python3 Reasoning.py
```
